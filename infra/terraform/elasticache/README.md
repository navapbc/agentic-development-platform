# elasticache

Reusable module that provisions the platform cache as ElastiCache for Valkey in the data tier. Langfuse uses it as its BullMQ job queue and its cache, so it runs with `noeviction` and an RBAC user rather than an unauthenticated default user. Nothing is created unless `create_cache = true`.

## What it provisions

- A Valkey 9.1 replication group with `num_cache_clusters` nodes, one by default. Two or more with `automatic_failover_enabled` and `multi_az_enabled` adds a replica in another Availability Zone.
- Encryption at rest with the AWS managed key or `kms_key_arn`, and TLS in transit set to `required`.
- A `valkey9` parameter group with `maxmemory-policy` set to `noeviction`, which Langfuse requires so queued jobs are never evicted.
- An RBAC user group holding one user, `langfuse` by default, with the access string `on ~* +@all` that Langfuse documents. Valkey user groups need no `default` user, so unauthenticated connections are refused.
- A Secrets Manager secret holding the user's initial credential as `username`, `password`, and `user_arn`, the format the ElastiCache rotation function reads. Terraform ignores later changes to the password, so a rotation does not cause drift.
- A security group that admits the cache port from `ingress_security_group_ids` and `ingress_cidr_blocks` and has no egress rule.
- Engine log delivery to a CloudWatch log group, and automatic snapshots kept for `snapshot_retention_days`.

## Credential lifecycle

The initial password is generated by Terraform, so it is present in state, which is stored encrypted in the remote backend. Attaching the Secrets Manager rotation function replaces it on the first rotation. The rotation calls the ElastiCache `ModifyUser` API, so the function needs no network path to the cache.

## Langfuse settings

| Variable | Value |
|---|---|
| `REDIS_HOST` | `primary_endpoint_address` |
| `REDIS_PORT` | `port` |
| `REDIS_USERNAME` | `username` |
| `REDIS_AUTH` | The `password` key of `user_secret_arn`, injected as an ECS task secret |
| `REDIS_TLS_ENABLED` | `true` |

Local development runs the same engine and RBAC user without TLS. See the README section on the local cache.

## Usage

```hcl
module "elasticache" {
  source = "../elasticache"

  create_cache        = true
  name_prefix         = "agentic-platform"
  vpc_id              = aws_vpc.this.id
  subnet_ids          = aws_subnet.data[*].id
  ingress_cidr_blocks = ["10.0.1.0/24"]
  tags                = var.tags
}
```
